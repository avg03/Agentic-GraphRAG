What changed in v2

  • Hierarchy-aware context index (graphrag/context_index.py): entity contexts are indexed along the graph hierarchy so lookups resolve which subgraph a phrase belongs to, not just that it exists.
  • Scope traversal (graphrag/scope.py + traverse.py): for set/aggregation questions the traversal identifies the full scope of matching entities (e.g. all events of a discipline) instead of a handful of seeds, and pulls the union of their chunks.
  • New agent action GRAPH_SCOPE (Pipeline 3): the agent can request a scope expansion when it detects an under-covered collection question; a coverage gate decides whether collected evidence is sufficient before answering.
  • Pipeline 2 (GraphRAG) ships with the v2 scope-capable code path — the same retrieval engine powers both the fixed pipeline and the agent's GRAPH_SCOPE tool.
